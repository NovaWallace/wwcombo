# WW Combo Trainer v0.7.1

## 中文更新日志

- 修复按键 Buff 计时的“不可刷新”选项仅在长按松开模式可用的问题。点按模式现在同样可以开启不可刷新、设置冷却秒数，并在切换触发模式后保留配置。
- Buff 持续时间与不可刷新冷却仍按游戏计时器计算；本体和完整 DLC 分别打包为 Windows x64 ZIP。
- 本体 ZIP 解压后以管理员模式运行 `wwcombo.exe`；如需视频、模拟输入及 Live2D 功能，再将完整 DLC ZIP 解压到 `wwcombo.exe` 所在目录。

## English Release Notes

- Fixed the non-refreshable Buff option being limited to hold-and-release triggers. Press triggers now support the option and cooldown duration, and switching trigger modes preserves the setting.
- Buff duration and cooldown remain tied to the in-game timer. Windows x64 core and full DLC are distributed as separate ZIPs.
- Extract the core ZIP and run `wwcombo.exe` as administrator. Extract the full DLC ZIP beside the executable for video, simulated input, and Live2D features.
