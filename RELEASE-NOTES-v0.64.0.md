# WW Combo Trainer 0.64.0

## Tutorial

- Added the official Bilibili video tutorial to the first-run guide and Settings > Help.
- The tutorial button opens in the system browser and is labeled in Chinese, English, Japanese, and Korean.

## Distribution

- Reorganized the Windows release into three downloads: the core portable app, the FFmpeg video-editing DLC, and the complete Live2D home-screen DLC pack.
- FFmpeg and Live2D remain optional. Recording, practice, timeline editing, Workshop, JSON import/export, and appearance settings continue to work from the core package.
- The complete Live2D pack contains the 35 individually installable character archives.
