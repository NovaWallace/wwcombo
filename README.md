# WW Combo Trainer / 鸣潮训练场

[中文](README.md) | [English](README_EN.md) | [日本語](README_JA.md) | [한국어](README_KO.md)

WW Combo Trainer 是一个用于《鸣潮》连段录制、编辑、练习和图片/视频输出的 Windows 桌面工具。它只读取输入用于记录与判定，不会替玩家向游戏发送按键。本项目是非官方粉丝项目，与库洛游戏无隶属关系。

## 安装与首次设置

1. 从 GitHub Releases 下载 `WW Combo Trainer_*_x64-setup.exe`，也可使用 MSI 安装包或带快捷方式与 FFmpeg 的便携版 ZIP。
2. 安装并启动程序。Windows 首次运行若显示来源提示，请确认文件来自本仓库 Release 后再继续。
3. 打开 `设置`，选择界面语言：中文、English、日本語或한국어。
4. 在 `输入模式` 中切换 `键鼠` 或 `手柄`，检查每个招式的绑定是否和游戏内一致。
5. 每个招式可以绑定两个按键。例如闪避可以同时设置 `Shift` 和鼠标右键。
6. 开启侧栏底部的全局输入监听后，即使游戏位于前台，桌面版也能接收按键。Windows 版启动时会自动请求管理员权限，请在 UAC 弹窗中选择“是”。

语言切换只改变界面和内置默认文本，不会改写用户的连段名、角色名、备注或自定义标签。

## 推荐使用流程

1. 在 `设置` 中确认键位。
2. 进入 `录制`，按开始键打一遍连段。
3. 在时间轴里修正招式、角色、时段和提示内容。
4. 保存到连段库，并导出 JSON 备份。
5. 在 `练习` 中学习和挑战。
6. 在 `外观` 中调整置顶连段图。
7. 需要静态图片时使用 `导出轴图`；需要成片时使用 `视频工具`。

## 录制

- 默认按 `F` 开始，按 `Esc` 结束；实际按键以设置页绑定为准。
- `替换`：用新录制结果替换当前编辑谱，适合新建或重录。
- `测试`：将新录制与当前谱匹配，用来修正已有谱的时间窗口。
- `视频工具`：当前已有谱面时，进入视频同步编辑。
- 长按普攻、技能、声骸、解放、闪避和跳跃会记录为对应的长按招式。

### 时间模式

- `添加`：选择招式后点击角色轨道放置；放置中按 `X` 可在招式和时段之间切换。
- 拖动招式块可改时间或轨道；拖动左右边缘可改开始时间和持续时间。
- 剪刀工具可在点击处拆分招式块。
- 按住 `Ctrl` 点选，或拖出选择框，可以同时选择多个块。
- `Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。
- 招式参数包括显示文本、备注、独立轨道、最早开始、最大持续时间、前摇和后摇。

### 时段

- `启动轴`：连段开头，起点固定为 0。
- `循环轴`：重复执行的部分；多轮不同时可以建立多个循环轴并设置轮次。
- `自由操作`：该范围内不按主轴顺序推进。
- 删除时段不会自动删除时段内的招式块。

### 内容模式

内容模式控制“显示什么”，不会改变招式实际时间。选择招式块后可编辑：

- `招式块文本`：置顶图和导出图显示的文字或图标映射文本。
- `备注`：练习时使用的提示文字。
- 空操作只能通过添加招式放入。它只参与显示，不参与练习和挑战判定。空操作文本为 `w`、`f`、`e` 等已知映射时，会使用前走、处决、技能等默认提示。

常用图标文本：`a` 普攻、`z` 重击、`e/E` 技能/长按技能、`q/Q` 声骸/长按声骸、`r/R` 解放/长按解放、`s` 或 `d` 闪避、`j` 跳跃、`f` 处决、`w` 前走、`i/ii/iii` 切换角色。

## 连段库、导入和分享

- 点击连段选择为当前谱；铅笔按钮进入编辑；删除按钮会二次确认。
- `导入` 读取兼容 JSON；`导出当前/全部` 用于备份和迁移。
- 分享 JSON 可填写名称、标签、说明和链接。标签包含轮椅、基础、标准、进阶、冒烟和全局。
- JSON 会保存招式时间、角色和轨道、时段、内容文本、外观、头像、底图、裁剪、图标与相关映射。
- 重要谱面在大改角色顺序、循环轴或时间线前应先导出备份。

## 练习

1. 进入 `练习` 并选择连段。
2. 选择 `演示`、`练习` 或 `挑战`。
3. 按开始键运行，按结束键停止。

- `演示`：按谱面时间自动播放，不要求输入。
- `练习`：输入正确招式后推进，适合学习顺序。
- `挑战`：使用更严格的时间与错误判定。
- `角色顺序`：拖动头像修改切人目标；练习运行中不能修改。
- `轴首招启动`：进入启动轴或循环轴时，等待该轴第一个关键输入后继续。
- `同角色合并`：将相邻的同角色显示项合并，具体上限在外观中设置。
- 黄色眼睛按钮控制置顶连段图显示。

## 外观

外观页控制练习和录制共用的置顶连段图。横排、竖排和瀑布流分别保存自己的窗口位置和参数。

- `横排/竖排/瀑布流`：选择显示方向或音游式下落布局。
- `移动`：允许拖动和缩放置顶窗口；定位后关闭移动，鼠标可继续穿透到游戏。
- `胶囊/底图`：使用纯色块或图片底图。
- `头像`：为每个角色选择在线预设或自定义图片，并调整裁剪。
- `全局底图`：所有没有独立覆盖的角色共用。
- `角色底图`：只覆盖指定角色；选择“复用全局”可取消覆盖。
- `底图裁剪`：X/Y/W/H 决定截取区域；左右拉伸线保护边框和两端装饰，只有中间区域随块宽拉伸。
- `图标`：配置文本到图片的映射、角色专属映射和图标大小。
- `图标转换`、`同角色合并`、`预提示`：控制最终显示方式，不改变谱面判定。
- 在招式内容中使用 `[Basic Attack]` 这类中括号写法，可让括号内内容按纯文字显示，不参与图标转换；中括号本身不会显示。
- `整体缩放、块高、间距、字体、头像大小和偏移、渐隐强度、合并上限`：只改变显示外观。

## 导出轴图

`实验 > 导出轴图` 用于把连段输出为一张 PNG：

1. 在右侧选择连段。
2. 默认展示启动轴和一个循环轴；只有一个循环轴时显示为“循环轴”。
3. 在 `内容` 中选择要展示的额外轮次，并调整单个招式块内容。
4. 在 `外观`、`底图` 和 `图标` 标签中设置这个模块独立使用的样式。这里的自定义不会覆盖全局外观。
5. 输入目标图片宽高。程序会根据连段块数量自动换行和缩放，不会强制拉大图片。
6. 检查左侧预览后导出 PNG。

启动轴和循环轴会作为可自动换行的连续连段块处理。角色专属底图、自定义裁剪、底图预设、自定义图标和映射都可在本模块单独配置。

## 实验工具

### 节奏轴

选择已保存的连段后开始挑战。设置中可调整舞台图层、轨道起点与判定点、判定区域、角色反馈图层和音频响应图层。图层支持位置、大小、透明度、旋转与排序。节奏轴的图标设置是独立副本，需要时可从全局图标配置重新复制。

### 按键映射

按下键位时显示对应图片，可用于键鼠或手柄操作展示。

- 图片层用于背景或装饰；按键层包含随输入显示的图片。
- 与招式关联的按键会跟随主设置页的双键绑定，无需在手柄模式重复添加。
- 预设保存完整图层、图片和位置配置。
- 设置可调整桌面窗口位置、画布大小和整体缩放。

## 视频工具

1. 先创建或选择一个连段，再从录制页打开视频工具。
2. 导入游戏视频，使用同步时间线对齐招式。
3. 空格播放/暂停；可切换 1x、0.5x、0.2x 速度。
4. 连段图初始外观来自外观页，可在视频预览中单独移动、缩放和裁剪。
5. 缩放关键帧用于制作视频画面推拉；时间线手柄可调整面板高度和缩放。
6. 桌面包优先导出 MP4；浏览器模式可能回退为 WebM。导出目录在设置页配置。

## 常见问题

- **游戏中没有输入**：检查绑定与输入模式，开启全局输入，并确认训练场与游戏权限级别一致。
- **置顶图不能点击或拖动**：临时开启 `移动`，定位完成后关闭。
- **图片裁剪变形**：先调整裁剪框，再调整左右拉伸线，不要让拉伸线越过彼此。
- **MP4 导出失败**：确认本次会话已导入视频，导出目录存在且可写，并使用完整安装包。
- **换语言后自定义内容没翻译**：这是预期行为；只翻译程序内置文本，不改写用户数据。

## 开发构建

需要 Node.js、Rust 和 Tauri 2 所需的 Windows 构建环境。

```powershell
npm install
npm run typecheck
npm run tauri:build
```

安装包输出到 `src-tauri/target/release/bundle/`。`scripts` 是独立社区站点工具，不属于桌面本体安装包。
