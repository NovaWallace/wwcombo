# WW Combo Trainer / 鳴潮トレーナー

[中文](README.md) | [English](README_EN.md) | [日本語](README_JA.md) | [한국어](README_KO.md)

WW Combo Trainer は、『鳴潮』のコンボを記録・編集・練習し、画像や動画として出力する Windows デスクトップツールです。入力は記録と判定のために読み取るだけで、ゲームへ自動入力を送信しません。本プロジェクトは非公式のファンプロジェクトであり、KURO GAMES とは関係ありません。

## インストールと初期設定

1. GitHub Releases から `WW Combo Trainer_*_x64-setup.exe` をダウンロードします。MSI版と、ショートカット／FFmpegを含むポータブルZIPも利用できます。
2. インストールして起動します。Windows が発行元について警告した場合は、本リポジトリの Release から取得したファイルであることを確認してから続行してください。
3. `設定` を開き、中文、English、日本語、한국어から表示言語を選択します。
4. `入力モード` で `キーボード・マウス` または `ゲームパッド` を選び、ゲーム内のキー設定と一致させます。
5. 各アクションには2つの入力を割り当てられます。たとえば回避に `Shift` とマウス右ボタンを同時に登録できます。
6. サイドバー下部のグローバル入力を有効にすると、ゲームが前面にある間もデスクトップ版が入力を受信できます。Windows版は起動時に管理者権限を要求するため、UACダイアログで「はい」を選んでください。

言語変更は内蔵UIと既定テキストだけに適用されます。ユーザーが入力したコンボ名、キャラクター名、メモ、ラベルは書き換えません。

## 基本の作業手順

1. 設定で入力割り当てを確認します。
2. `記録` を開き、コンボを一度実行します。
3. タイムラインでアクション、キャラクター、区間、表示内容を修正します。
4. コンボライブラリに保存し、JSON バックアップを出力します。
5. `練習` で手順を覚えます。
6. `外観` で常に最前面のコンボ表示を整えます。
7. 静止画は `エクスポート軸`、動画は `ビデオツール` を使用します。

## 記録

- 既定では `F` で開始し、`Esc` で終了します。実際には設定ページの割り当てが優先されます。
- `置き換え`：新しい記録を現在の編集チャートとして使用します。
- `テスト`：新しい実行を現在のチャートに照合し、タイミング範囲を調整します。
- `ビデオツール`：既存チャートを使って動画同期編集を開きます。
- 通常攻撃、共鳴スキル、音骸スキル、共鳴解放、回避、ジャンプの長押しは、それぞれ対応する長押しアクションとして記録されます。

### タイミングモード

- `追加` を押し、アクションを選択してキャラクターレーンをクリックします。配置中に `X` を押すと、利用可能な場合はアクションと区間を切り替えます。
- ブロックをドラッグすると時間やレーンを変更できます。左右端をドラッグすると開始時刻や長さを変更できます。
- はさみツールでクリック位置からブロックを分割できます。
- `Ctrl` を押しながらクリックするか、範囲選択して複数ブロックを選択できます。
- `Ctrl+Z` で元に戻し、`Ctrl+Y` または `Ctrl+Shift+Z` でやり直します。
- アクションには、表示テキスト、メモ、独立レーン、最速開始、最大時間、前隙、後隙を設定できます。

### 区間

- `開始軸`：コンボの開始部分で、開始位置は 0 に固定されます。
- `ループ軸`：繰り返す部分です。周回ごとに内容が異なる場合は複数作成できます。
- `自由アクション`：通常のメイン軸順序に従わず入力できる範囲です。
- 区間を削除しても、その中のアクションブロックは自動削除されません。

### コンテンツモード

コンテンツモードは表示内容だけを変更し、アクションの時間は変更しません。

- `ブロックテキスト`：オーバーレイと出力画像に表示する内容です。
- `メモ`：練習時のヒントです。
- 空アクションは追加機能からのみ配置できます。表示専用で、練習とチャレンジの判定対象にはなりません。テキストが `w`、`f`、`e` などの既知のマッピングなら、前進、フィニッシャー、共鳴スキルなどの既定ヒントを使用します。

主なアイコン文字：`a` 通常攻撃、`z` 重撃、`e/E` スキル/長押しスキル、`q/Q` 音骸/長押し音骸、`r/R` 解放/長押し解放、`s` または `d` 回避、`j` ジャンプ、`f` フィニッシャー、`w` 前進、`i/ii/iii` キャラクター切替。

## コンボライブラリ、インポート、共有

- コンボをクリックして選択し、鉛筆で編集、削除ボタンで確認後に削除します。
- インポートは互換 JSON を読み込みます。現在/すべてのエクスポートはバックアップや移行に使用します。
- 共有 JSON には名前、タグ、説明、任意のリンクを設定できます。タグには簡単ループ、基礎、標準、上級、ショーケース、グローバルがあります。
- JSON にはタイミング、キャラクター、レーン、区間、表示テキスト、外観、アバター、背景、クロップ、アイコンとマッピングが保存されます。
- キャラクター順、ループ軸、タイムラインを大きく変更する前にバックアップしてください。

## 練習

1. `練習` を開いてコンボを選択します。
2. `デモ`、`練習`、`チャレンジ`を選びます。
3. 設定した開始/停止入力で実行します。

- `デモ`：タイムラインどおりに自動再生し、入力は不要です。
- `練習`：正しい入力後に次へ進み、順序の学習に適しています。
- `チャレンジ`：より厳しい時間判定とエラー判定を使用します。
- `キャラクター順`：ポートレートをドラッグして切替先を変更します。実行中は変更できません。
- `軸の先頭アクションから開始`：開始軸やループ軸に入る際、その軸の最初の重要入力を待ちます。
- `同キャラクターを結合`：隣接する同キャラクター表示をまとめます。上限は外観で設定します。
- 黄色の目ボタンで常に最前面のコンボ表示を切り替えます。

## 外観

外観は記録と練習で共用するコンボ表示を制御します。横、縦、ウォーターフォールは、それぞれ独立したウィンドウ位置と設定を保持します。

- `移動`：ウィンドウのドラッグとサイズ変更を有効にします。配置後に無効化すると、クリックがゲームへ通る状態に戻ります。
- `カプセル/背景`：色付きブロックまたは画像背景を選びます。
- `アバター`：各キャラクターのオンラインプリセットまたは自作画像を選び、クロップを調整します。
- `グローバル背景`：個別設定がないキャラクターで共用します。
- `キャラクター背景`：そのキャラクターだけを上書きします。「グローバルを使用」で解除します。
- 背景の X/Y/W/H は切り抜き範囲です。左右の伸縮ガイドは枠と端の装飾を保護し、中央部分だけを伸ばします。
- `アイコン`：文字から画像へのマッピング、キャラクター別マッピング、アイコンサイズを設定します。
- アイコン変換、同キャラクター結合、事前ヒントは表示だけに影響し、判定は変更しません。
- アクション内容を角括弧で囲むと文字のまま表示できます。たとえば `[Basic Attack]` はアイコンに変換されず `Basic Attack` と表示され、括弧自体は表示されません。
- 全体倍率、ブロック高、間隔、フォント、アバター位置、フェード、結合上限も表示専用です。

## エクスポート軸

`実験 > エクスポート軸` はコンボ全体を PNG にします。

1. 右側でコンボを選択します。
2. 既定では開始軸と1つのループ軸を表示します。ループが1つだけなら番号は付きません。
3. `コンテンツ` で追加周回を選び、各ブロックの内容を調整します。
4. `外観`、`背景`、`アイコン` でこのモジュール専用の設定を行います。グローバル外観は上書きしません。
5. 画像の幅と高さを入力します。ブロック数に応じて自動改行・自動縮小され、画像サイズを強制的に大きくしません。
6. 左側の大きなプレビューを確認して PNG を出力します。

開始軸とループ軸は、自動改行可能な連続コンボブロックとして扱われます。キャラクター別背景、カスタムクロップ、背景プリセット、カスタムアイコンとマッピングもこのモジュール内で利用できます。

## 実験ツール

### リズム軸

保存済みコンボを選んでチャレンジを開始します。設定では舞台レイヤー、レーンの開始/判定点、判定範囲、キャラクターフィードバック、音声反応レイヤーを調整できます。各レイヤーは位置、サイズ、不透明度、回転、順序に対応します。アイコン設定は独立コピーで、必要に応じてグローバル設定から再コピーできます。

### キー割り当て

キーボード、マウス、ゲームパッド入力中にカスタム画像を表示します。

- 画像レイヤーは背景や装飾、キーレイヤーは入力に反応する画像です。
- アクション連動画像はメイン設定の2つの入力割り当てに追従します。ゲームパッド用に重複登録する必要はありません。
- プリセットにはレイヤー、画像、位置の完全な設定が保存されます。
- 設定でデスクトップ位置、キャンバスサイズ、全体倍率を変更できます。

## ビデオツール

1. コンボを作成または選択し、記録ページからビデオツールを開きます。
2. プレイ動画を読み込み、同期タイムラインでアクションを合わせます。
3. Space で再生/一時停止します。速度は 1x、0.5x、0.2x です。
4. コンボレイヤーは外観設定から開始し、動画プレビュー内では独立して移動、拡大、クロップできます。
5. ズームキーフレームで画面の寄り引きを作成できます。タイムラインハンドルでパネル高さと表示倍率を調整します。
6. デスクトップ版は MP4 を優先し、ブラウザ版は WebM にフォールバックする場合があります。出力先は設定で指定します。

## トラブルシューティング

- **ゲーム中に入力されない**：割り当てと入力モードを確認し、グローバル入力を有効にして、ゲームと同じ権限で実行します。
- **オーバーレイを移動できない**：一時的に `移動` を有効にし、配置後に無効化します。
- **背景が変形する**：先にクロップを調整し、その後で左右の伸縮ガイドを調整します。ガイドを交差させないでください。
- **MP4 出力に失敗する**：現在のセッションで動画を読み込み、書き込み可能な出力先と完全版パッケージを使用します。
- **言語を変えても自作テキストが変わらない**：正常な動作です。内蔵テキストだけが翻訳されます。

## 開発ビルド

Node.js、Rust、Tauri 2 の Windows ビルド環境が必要です。

```powershell
npm install
npm run typecheck
npm run tauri:build
```

インストーラーは `src-tauri/target/release/bundle/` に生成されます。`scripts` は独立したコミュニティサイト用ツールであり、デスクトップ本体には含まれません。
