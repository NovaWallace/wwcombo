# WW Combo Trainer / 명조 트레이너

[中文](README.md) | [English](README_EN.md) | [日本語](README_JA.md) | [한국어](README_KO.md)

WW Combo Trainer는 명조 콤보를 기록, 편집, 연습하고 이미지나 영상으로 내보내는 Windows 데스크톱 도구입니다. 입력은 기록과 판정을 위해 읽기만 하며 게임에 자동 입력을 보내지 않습니다. 이 프로젝트는 비공식 팬 프로젝트이며 KURO GAMES와 관련이 없습니다.

## v0.3.0 업데이트 (2026-07-30)

- 4개 언어 내장 도움말, 연습 사용자/공략 제작자 튜토리얼, 상세 단축키, 전체 업데이트 기록과 첫 실행 안내를 추가했습니다.
- 설정에 `.wwkeys.json` 입력 설정 가져오기/내보내기와 단일 키/Shift 조합을 바꾸는 단축키 설정을 추가했습니다. Ctrl/Alt로 시작하는 편집 조합은 고정됩니다.
- Windows 버전은 시작할 때 관리자 권한을 필수로 요청합니다. 전역 입력 캡처, 마우스 측면 버튼, 이중 바인딩과 게임패드 입력 경로를 개선했습니다.
- `Delete`, `Ctrl+C`, `Ctrl+V`를 수정하고 `C` 분할과 `V` 병합을 추가했습니다. 선택이 없을 때 Delete는 연속 삭제가 되며 충돌하는 브라우저 기본 동작도 차단합니다.
- 추가 중 `F`는 피니셔, `B`는 변주 자동 전환을 선택합니다. 선택 블록에서 `Y`를 누르면 반주를 추가하며 피니셔, 변주, 반주와 앞으로 이동의 기본 안내도 표시합니다.
- `[Basic Attack]`처럼 대괄호 안의 문구를 문자 그대로 표시할 수 있습니다. 아이콘 변환에서 제외되고 표시할 때 괄호는 숨겨집니다.
- 오른쪽 클릭 메뉴에 “변경”과 “병합”을 추가하고 빈 공간에서도 현재 선택을 조작할 수 있게 했습니다. 블록 이동과 `Alt` 드래그 준비/후딜 편집도 수정했습니다.
- 외형에 문자 외곽선, 배경 가장자리 보호, 팀 프리셋과 실제 키 아이콘을 추가하고 기본 자르기와 밝은 테마 가독성을 개선했습니다.
- 녹화 타임라인에 재생, 배속, 자동 따라가기를 추가하고 흰색 재생 헤드 중심 확대를 적용했습니다. 영상 자르기와 5개 도구/다기능 버튼 배치도 개선했습니다.
- 세 테마의 홈 배경, 아이콘과 Live2D를 개선하고 Live2D 끄기를 추가했습니다. 진입 버튼 표시 눈 아이콘의 배경과 위치 이동도 수정했습니다.
- 녹화 대기 중에는 녹색, 녹화 중에는 빨간색 상태 점을 표시합니다. 축 이미지, 키 매핑과 영상 출력도 계속 개선했습니다.

## 설치 및 초기 설정

1. GitHub Releases에서 `WW Combo Trainer_*_x64-setup.exe`를 다운로드합니다. MSI와 바로가기/FFmpeg가 포함된 포터블 ZIP도 제공됩니다.
2. 설치 후 실행합니다. Windows가 출처 경고를 표시하면 이 저장소의 Release에서 받은 파일인지 확인한 뒤 계속하세요.
3. `설정`에서 中文, English, 日本語, 한국어 중 인터페이스 언어를 선택합니다.
4. `입력 모드`에서 `키보드 및 마우스` 또는 `게임패드`를 선택하고 게임 내 설정과 동일하게 맞춥니다.
5. 각 동작에는 입력을 두 개까지 지정할 수 있습니다. 예를 들어 회피에 `Shift`와 마우스 오른쪽 버튼을 함께 등록할 수 있습니다.
6. 사이드바 아래의 전역 입력을 켜면 게임이 앞에 있어도 데스크톱 앱이 입력을 받을 수 있습니다. Windows 버전은 시작할 때 관리자 권한을 요청하므로 UAC 창에서 “예”를 선택하세요.

언어 변경은 내장 인터페이스와 기본 문구만 바꿉니다. 사용자가 작성한 콤보 이름, 캐릭터 이름, 메모, 라벨은 다시 쓰지 않습니다.

## 권장 작업 순서

1. 설정에서 입력 바인딩을 확인합니다.
2. `기록`을 열고 콤보를 한 번 수행합니다.
3. 타임라인에서 동작, 캐릭터, 구간, 표시 내용을 수정합니다.
4. 콤보 라이브러리에 저장하고 JSON 백업을 내보냅니다.
5. `연습`에서 순서를 익힙니다.
6. `외관`에서 항상 위에 표시되는 콤보 차트를 꾸밉니다.
7. 정지 이미지는 `축 내보내기`, 영상은 `비디오 도구`를 사용합니다.

## 기록

- 기본 입력은 `F`로 시작하고 `Esc`로 종료합니다. 실제로는 설정 페이지의 바인딩이 우선합니다.
- `교체`는 새 기록을 현재 편집 차트로 사용합니다.
- `테스트`는 새 실행을 현재 차트와 비교해 타이밍 범위를 보정합니다.
- `비디오 도구`는 차트가 있을 때 동기화 영상 편집을 엽니다.
- 일반 공격, 공명 스킬, 에코 어빌리티, 공명 해방, 회피, 점프를 길게 누르면 대응하는 길게 누르기 동작으로 기록됩니다.

### 타이밍 모드

- `추가`를 누르고 동작을 고른 다음 캐릭터 레인을 클릭합니다. 배치 중 `X`를 누르면 가능한 경우 동작과 구간 배치를 전환합니다.
- 블록을 드래그해 시간이나 레인을 바꿉니다. 양쪽 가장자리를 드래그하면 시작 시각이나 길이를 바꿀 수 있습니다.
- 가위 도구로 클릭한 위치에서 블록을 나눕니다.
- `Ctrl`을 누른 채 클릭하거나 선택 사각형을 드래그해 여러 블록을 선택합니다.
- `Ctrl+Z`는 실행 취소, `Ctrl+Y` 또는 `Ctrl+Shift+Z`는 다시 실행입니다.
- 동작에는 표시 문구, 메모, 독립 레인, 가장 빠른 시작, 최대 지속 시간, 선딜레이, 후딜레이를 설정할 수 있습니다.

### 구간

- `시작 축`은 콤보 시작 부분이며 시작점이 0으로 고정됩니다.
- `루프 축`은 반복 구간입니다. 회차마다 내용이 다르면 여러 루프 축을 만들 수 있습니다.
- `자유 동작`은 일반 메인 축 순서 없이 입력할 수 있는 범위입니다.
- 구간을 삭제해도 안에 있는 동작 블록은 자동으로 삭제되지 않습니다.

### 콘텐츠 모드

콘텐츠 모드는 보이는 내용만 바꾸며 동작 타이밍은 바꾸지 않습니다.

- `블록 텍스트`는 오버레이와 내보낸 이미지에 표시됩니다.
- `메모`는 연습 힌트입니다.
- 빈 동작은 추가 기능으로만 배치할 수 있습니다. 표시 전용이므로 연습과 도전 판정에서 제외됩니다. 텍스트가 `w`, `f`, `e`처럼 알려진 매핑이면 앞으로 이동, 피니셔, 공명 스킬 등의 기본 힌트를 사용합니다.

대표 아이콘 텍스트: `a` 일반 공격, `z` 강공격, `e/E` 스킬/길게 누르기, `q/Q` 에코/길게 누르기, `r/R` 해방/길게 누르기, `s` 또는 `d` 회피, `j` 점프, `f` 피니셔, `w` 앞으로 이동, `i/ii/iii` 캐릭터 전환.

## 콤보 라이브러리, 가져오기, 공유

- 콤보를 클릭해 선택하고 연필 버튼으로 편집합니다. 삭제는 확인 후 진행됩니다.
- 가져오기는 호환 JSON을 읽습니다. 현재/전체 내보내기는 백업과 이동에 사용합니다.
- 공유 JSON에는 이름, 태그, 설명, 선택 링크를 넣을 수 있습니다. 태그에는 쉬운 루프, 기초, 표준, 고급, 쇼케이스, 전역이 있습니다.
- JSON에는 동작 타이밍, 캐릭터, 레인, 구간, 표시 문구, 외관, 아바타, 배경, 자르기, 아이콘과 매핑이 저장됩니다.
- 캐릭터 순서, 루프 축, 타임라인을 크게 수정하기 전에 백업을 내보내세요.

## 연습

1. `연습`을 열고 콤보를 선택합니다.
2. `데모`, `연습`, `도전` 중 하나를 선택합니다.
3. 설정한 시작/종료 입력으로 실행합니다.

- `데모`는 타임라인에 따라 자동 재생하며 입력이 필요 없습니다.
- `연습`은 올바른 입력 후 다음 단계로 넘어가므로 순서를 익히기에 좋습니다.
- `도전`은 더 엄격한 타이밍과 오류 판정을 사용합니다.
- `캐릭터 순서`는 초상화를 드래그해 전환 대상을 바꿉니다. 실행 중에는 바꿀 수 없습니다.
- `축 첫 동작에서 시작`은 시작 축이나 루프 축에 들어갈 때 첫 핵심 입력을 기다립니다.
- `같은 캐릭터 병합`은 인접한 같은 캐릭터 표시를 합칩니다. 병합 한도는 외관에서 설정합니다.
- 노란색 눈 버튼은 항상 위 콤보 차트를 표시하거나 숨깁니다.

## 외관

외관은 기록과 연습에서 공유하는 콤보 차트를 제어합니다. 가로, 세로, 워터폴은 각각 독립된 창 위치와 설정을 보관합니다.

- `이동`은 창 드래그와 크기 조절을 켭니다. 배치 후 끄면 클릭이 게임으로 통과합니다.
- `캡슐/배경`은 색상 블록 또는 이미지 배경을 선택합니다.
- `아바타`는 각 캐릭터의 온라인 프리셋이나 사용자 이미지를 고르고 자르기를 조정합니다.
- `전역 배경`은 개별 덮어쓰기가 없는 캐릭터에 사용됩니다.
- `캐릭터 배경`은 해당 캐릭터만 덮어씁니다. 전역 사용을 선택하면 덮어쓰기를 해제합니다.
- 배경 X/Y/W/H는 자르기 영역입니다. 왼쪽/오른쪽 늘이기 가이드는 테두리와 끝 장식을 보호하고 중앙만 늘어납니다.
- `아이콘`은 텍스트-이미지 매핑, 캐릭터별 매핑, 아이콘 크기를 설정합니다.
- 아이콘 변환, 같은 캐릭터 병합, 사전 힌트는 표시만 바꾸며 판정에는 영향을 주지 않습니다.
- 동작 내용을 대괄호로 감싸면 문자 그대로 표시됩니다. 예를 들어 `[Basic Attack]`은 아이콘으로 바뀌지 않고 `Basic Attack`으로 표시되며 괄호는 보이지 않습니다.
- 전체 배율, 블록 높이, 간격, 글꼴, 아바타 위치, 페이드, 병합 한도도 표시 전용입니다.

## 축 내보내기

`실험 > 축 내보내기`는 전체 콤보를 PNG로 만듭니다.

1. 오른쪽에서 콤보를 선택합니다.
2. 기본적으로 시작 축과 루프 축 하나를 표시합니다. 루프가 하나뿐이면 번호를 붙이지 않습니다.
3. `콘텐츠`에서 추가 회차를 선택하고 각 블록 내용을 조정합니다.
4. `외관`, `배경`, `아이콘`에서 이 모듈 전용 설정을 합니다. 전역 외관은 덮어쓰지 않습니다.
5. 이미지 너비와 높이를 입력합니다. 블록 수에 따라 자동 줄바꿈과 자동 축소가 적용되며 이미지 크기를 강제로 키우지 않습니다.
6. 왼쪽 큰 미리보기를 확인한 뒤 PNG를 내보냅니다.

시작 축과 루프 축은 자동 줄바꿈 가능한 연속 콤보 블록으로 처리됩니다. 캐릭터별 배경, 사용자 자르기, 배경 프리셋, 사용자 아이콘과 매핑도 이 모듈 안에서 사용할 수 있습니다.

## 실험 도구

### 리듬 축

저장된 콤보를 선택하고 도전을 시작합니다. 설정에서 스테이지 레이어, 레인 시작/판정 지점, 판정 영역, 캐릭터 피드백, 오디오 반응 레이어를 조정합니다. 레이어는 위치, 크기, 불투명도, 회전, 순서를 지원합니다. 아이콘 설정은 독립 복사본이며 필요할 때 전역 설정에서 다시 복사할 수 있습니다.

### 키 매핑

키보드, 마우스, 게임패드 입력을 누르는 동안 사용자 이미지를 표시합니다.

- 이미지 레이어는 배경이나 장식이며 키 레이어는 입력에 반응하는 이미지입니다.
- 동작 연결 이미지는 기본 설정 페이지의 두 바인딩을 모두 따릅니다. 게임패드 모드에서 중복 항목을 만들 필요가 없습니다.
- 프리셋은 레이어, 이미지, 위치 전체 설정을 저장합니다.
- 설정에서 데스크톱 창 위치, 캔버스 크기, 전체 배율을 조정합니다.

## 비디오 도구

1. 콤보를 만들거나 선택한 뒤 기록 페이지에서 비디오 도구를 엽니다.
2. 플레이 영상을 가져오고 동기화 타임라인에서 동작을 맞춥니다.
3. Space로 재생/일시 정지합니다. 속도는 1x, 0.5x, 0.2x입니다.
4. 콤보 레이어는 외관 설정에서 시작하며 영상 미리보기에서는 독립적으로 이동, 확대, 자르기 할 수 있습니다.
5. 줌 키프레임으로 화면 확대/축소 효과를 만듭니다. 타임라인 핸들로 패널 높이와 타임라인 배율을 조정합니다.
6. 데스크톱 패키지는 MP4를 우선 내보내며 브라우저 모드는 WebM으로 대체될 수 있습니다. 출력 폴더는 설정에서 지정합니다.

## 문제 해결

- **게임이 앞에 있을 때 입력이 감지되지 않음:** 바인딩과 입력 모드를 확인하고 전역 입력을 켠 뒤 게임과 같은 권한으로 실행합니다.
- **오버레이를 드래그할 수 없음:** 잠시 `이동`을 켜고 배치 후 다시 끕니다.
- **배경이 찌그러짐:** 먼저 자르기를 맞춘 다음 왼쪽/오른쪽 늘이기 가이드를 조정하고 서로 교차하지 않게 합니다.
- **MP4 내보내기 실패:** 현재 세션에서 영상을 가져왔는지, 출력 폴더에 쓰기 권한이 있는지, 완전한 패키지를 사용하는지 확인합니다.
- **언어를 바꿔도 사용자 문구가 바뀌지 않음:** 정상입니다. 내장 문구만 번역됩니다.

## 개발 빌드

Node.js, Rust, Tauri 2용 Windows 빌드 환경이 필요합니다.

```powershell
npm install
npm run typecheck
npm run tauri:build
```

설치 파일은 `src-tauri/target/release/bundle/`에 생성됩니다. `scripts`는 별도의 커뮤니티 사이트 도구이며 데스크톱 앱 패키지에 포함되지 않습니다.
