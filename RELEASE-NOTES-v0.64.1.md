# WW Combo Trainer 0.64.1

## Input Capture

- Fixed global input capture for native PlayStation controllers, including DualSense and DualShock devices exposed through Windows Gaming Input, Raw Game Controller, or USB HID.
- Kept keyboard, Xbox, and PlayStation capture mutually exclusive so only the selected input backend runs.
- Preserved PlayStation face-button labels, triggers, D-pad directions, and modifier combinations throughout the capture chain.

## Core Package

- Buff recognition/timer and automatic simulated-input controls are not included in this release build.
- FFmpeg and Live2D remain optional DLC downloads beside the core package.
